# Sample · Pulso de marca Renner

Página estática, sem build. Todos os números são fictícios.
O conteúdo do `index.html` fica criptografado (AES-256-GCM com PBKDF2) e só abre com a senha, que deve ser repassada por canal separado.

## Publicar no GitHub Pages
1. Suba `index.html`, `404.html`, `robots.txt` e `.nojekyll` na raiz do repositório.
2. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. O link fica em `https://<usuario>.github.io/<repositorio>/` em 1 a 2 minutos.
